# GDMazeGame
This was my bachelor thesis project. 
The idea is: 
- Generate a maze, let the player solve it and gather analysis data on how the player solves it. 
- Then have another screen where we can see the maze and path, heatmap (most visited cells) and collisions with the maze's walls.

There is also a 2Player split-screen mode, so you can play it with a friend at home :)
Also there's a little incentive - coins. Gather coins and buy yourself new outfits for your character to wear.
